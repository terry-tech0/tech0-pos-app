## 決まったこと

**設計仕様書の確認事項 T-1〜T-7 は、下記で実装した**（コード内のコメントに根拠あり）。設計側での正式確定はまだ。

| # | 決めた内容 |
|---|---|
| T-1 | 按分の余り1円は、税抜小計が同額なら**軽減8%側**へ寄せる |
| T-2 | 明細0件を計算クラスに渡したら **`ValueError`**（API層は先に `E-TXN-002` で弾く） |
| T-3 | 合計が上限9,999,999超は **`E-VAL-001`**（入力値違反として扱う） |
| T-4 | 「非会員として続行」後は、会員欄を「非会員」表示・入力欄クリア・フォーカスを商品コード欄へ |
| T-5 | 8桁と13桁は**別商品**として扱う（`product_code` が主キー。名寄せはLv2で作らない） |
| T-6 | `calculate` の引数は **`CalcLine` dataclass**（`unit_price`/`quantity`/`tax_category` の3つだけ） |
| T-7 | 税抜合計0円のときは**按分をスキップ**（ゼロ除算を避ける） |

**設計書からの逸脱1件**

- `jest` の変換に `ts-jest` ではなく **`@swc/jest`** を使った。設計§2.1 が採用した TypeScript 7.0.2 に対し、`ts-jest` の対応が `>=4.3 <7` で TS7 を受け付けないため。TypeScript 本体は設計どおり 7.0.2。

**画面側の計算の強化**

設計より一歩踏み込んで、税率を1/10000単位の整数に直して**整数演算だけ**で計算した。テスト仕様書§10.4 は「現在の税率では実害なし」までだったが、この実装なら**税率が変わっても再検証が不要**（REQ-08 で税率は変わる前提のため）。

## 次の一手（Mac で最初にやること）

### 1. 取り込み

```bash
cd ~/dev/tech0/tech0-pos-app   # ← Mac側の実際のパスに読み替え
git pull
```

### 2. 接続設定ファイルを作る（★gitに乗らないので現地で作成が必要）

**バックエンド** `src/backend/.env` — `src/backend/.env.example` をコピーして記入。

- `DATABASE_URL` — 形式は `mysql+pymysql://ユーザー:パスワード@ホスト/pos_terry`
  - **パスワードに `&` と `@` が含まれるので、URLに入れる前に必ずエンコードする**（`&`→`%26`、`@`→`%40`）。素のままだと `@` が「ユーザー情報とホストの区切り」と解釈されて接続先を誤認する
  - スキーマ名は `pos_terry`（共有サーバなので自分専用のスキーマを作る。課題の「スキーマ新規追加」に対応）
  - 接続情報は講師の Slack 投稿を参照
- `DB_SSL=true`（Azure は SSL 必須）
- `JWT_SECRET_KEY` — 32バイト以上のランダム値。`python3 -c "import secrets; print(secrets.token_urlsafe(48))"` で生成

**フロントエンド** `src/frontend/.env.local` — `.env.local.example` をコピー。`BACKEND_API_BASE_URL=http://127.0.0.1:8000`

### 3. 環境を作る

```bash
cd src/backend
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt

cd ../frontend
npm install
```

### 4. DBにつないでテーブルとデータを作る

```bash
cd src/backend
.venv/bin/python -m scripts.init_db      # テーブル6つを作成
export SEED_CASHIER_PASSWORD='任意のテスト用パスワード'
.venv/bin/python -m scripts.seed         # fixtures のCSVを投入
```

つながらない場合は、Azureポータルの「ネットワーク」で**自宅のグローバルIPを許可**する必要があるかもしれない（講師が全許可にしていれば不要）。

### 5. 動かして通しで確認

```bash
# ターミナル1
cd src/backend && .venv/bin/python -m uvicorn app.main:app --reload --port 8000
# ターミナル2
cd src/frontend && npm run dev            # http://localhost:3000
```

ログインは `cashier01`（店長は `manager01`）、パスワードは手順4で設定した値。

**最初に確認する1件**：会員 `1000000001` で、おにぎり `4901234567894`×2・牛乳 `4901234567900`×1・洗剤 `4902345678901`×1 を登録し、**税込798円**になって購入できること。これが通れば主要な経路はすべて動いている。
